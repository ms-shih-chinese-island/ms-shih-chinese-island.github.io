Recording Studio (for Ms. Shih)

怎么用 How to use

  1. 上面选要录的东西：单元的生词（跟图书馆一样的章）、常用句型片段（我喜欢、这是、穿、的……），或是最近听过的句子（这台电脑玩游戏时念过的）。
  2. 按 ⏺ 开始录音，说完再按 ⏹ 停止。录完会马上放一次给你听，不满意就再录。前后的空白会自动剪掉，音量也会调成差不多大。
  3. 关卡的句子是随机组合的：网站会把你录过的字词接起来念。「最近听过的句子」会显示 ✓ 可以接起来念，或是「还缺：穿、黄色」。
  4. 录好的会先存在这台电脑里，关掉网页也还在。录完按「下载录音包」，把 voice.zip 传给 Claude。

录音只存在你自己的电脑，不会自动传到任何地方。第一次录音时，浏览器会问可不可以用麦克风，请按「允许」。
